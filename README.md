# bkh-media

Öffentliche Mediendateien des Instagram-Kanals [@hankundholly](https://www.instagram.com/hankundholly/).

- Branch `claude/media`: fertig gerenderte Reels, Cover und Karussell-Bilder, die Instagram von hier abruft. Alle Dateien sind ohne Metadaten (kein Ort, kein Aufnahmedatum).
- Branch `main`: diese Beschreibung, später das Impressum.

Hier liegt nichts Vertrauliches und kein Rohmaterial.
